You can use Justified Gallery with any lightbox, in the way you prefer. In this tutorial we use [GLightbox](https://github.com/biati-digital/glightbox), a modern lightbox with no dependencies, but the same principles can be applied to any other lightbox (for example [PhotoSwipe](https://photoswipe.com/), which additionally requires the image dimensions in `data-pswp-*` attributes on every link).

## GLightbox

GLightbox works directly with the standard Justified Gallery markup: a series of links to the original images, each containing a thumbnail. Install it, initialize the gallery, and attach the lightbox to the entry links:

```bash
npm install glightbox
```

```js
import { JustifiedGallery } from 'justified-gallery';
import 'justified-gallery/style.css';
import GLightbox from 'glightbox';
import 'glightbox/dist/css/glightbox.min.css';

const container = document.getElementById('gallery');
const gallery = new JustifiedGallery(container, {
  lastRow: 'nojustify',
  rowHeight: 100,
  margins: 1,
});
gallery.init();

const lightbox = GLightbox({ selector: '#gallery a' });

// on teardown (e.g. a route change):
// gallery.destroy();
// lightbox.destroy();
```

Try it out — click any image:

## Grouping with `rel` and `target`

Some lightboxes group images into a gallery through the `rel` attribute of the links. Justified Gallery can rewrite that attribute for you on every entry with the [`rel` option](/Justified-Gallery/options-and-events/), and similarly the `target` attribute with the `target` option:

```js
const gallery = new JustifiedGallery(container, {
  rel: 'gallery1',
});
gallery.init();
```

## Multiple galleries in one page

Each gallery needs its own `JustifiedGallery` instance, and its own lightbox group. Just loop over the containers:

```html
<div class="gallery justified-gallery">
  <a href="image1.jpg"><img alt="title 1" src="image1_thumbnail.jpg" /></a>
  ...
</div>
<div class="gallery justified-gallery">
  <a href="image3.jpg"><img alt="title 3" src="image3_thumbnail.jpg" /></a>
  ...
</div>
```

```js
const galleries = [...document.querySelectorAll('.gallery')].map((container, i) => {
  container.id = `gallery-${i}`;
  const gallery = new JustifiedGallery(container, { rel: `gallery-${i}` });
  gallery.init();
  GLightbox({ selector: `#gallery-${i} a` });
  return gallery;
});
```
