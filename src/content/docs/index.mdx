Justified Gallery is a **zero-dependency JavaScript library**, written in TypeScript, that lets you create a **high quality justified gallery** of images. It works with plain HTML, React, Vue, or any other framework.

It solves a common problem for people who build websites: you have a series of images to display, but you are not sure how to arrange them elegantly. Important websites such as 500px, Flickr, or Google display images in an excellent way, justifying them similarly to a **brick wall**. Justified Gallery gives you the power to do that too.

Justified Gallery is a **professional and open source library** that even 500px, one of the best photography social networks, chose to display its images!

## Install

```bash
npm install justified-gallery
```

## How to use it

Justified Gallery works on standard markup: a container with a series of links, each with a thumbnail inside and pointing to the original image.

```html
<div id="gallery" class="justified-gallery">
  <a href="path/to/image1.jpg">
    <img alt="Title 1" src="path/to/image1_thumbnail.jpg" />
  </a>
  <a href="path/to/image2.jpg">
    <img alt="Title 2" src="path/to/image2_thumbnail.jpg" />
  </a>
  <!-- other images... -->
</div>
```

Justified Gallery also accepts other [input formats](/Justified-Gallery/input-formats/), to better fit your needs.

Import the library and its stylesheet, create a gallery on the container and initialize it. It's a plain class with zero dependencies and TypeScript types included, so it fits any stack:

<Tabs syncKey="framework">
  <TabItem label="Vanilla JS" icon="seti:javascript">

```ts
import { JustifiedGallery } from 'justified-gallery';
import 'justified-gallery/style.css';

const container = document.getElementById('gallery')!;
const settings = { rowHeight: 160 };

const gallery = new JustifiedGallery(container, settings);

gallery.init();
```
  </TabItem>
  <TabItem label="React" icon="seti:react">

```tsx
import { useEffect, useRef } from 'react';
import { JustifiedGallery } from 'justified-gallery';
import 'justified-gallery/style.css';

export function Gallery(images) {
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const gallery = new JustifiedGallery(
      containerRef.current, 
      { rowHeight: 160 }
    );

    gallery.init();
    
    return () => gallery.destroy();
  }, []);

  return (
    <div ref={containerRef} className="justified-gallery">
      {images.map((image) => (
        <a key={image.src} href={image.src}>
          <img src={image.thumb} alt={image.alt} />
        </a>
      ))}
    </div>
  );
}

```

More in the [React guide](/Justified-Gallery/react/).

  </TabItem>
  <TabItem label="Vue" icon="seti:vue">

```vue
<script setup lang="ts">
import { onBeforeUnmount, onMounted, ref } from 'vue';
import { JustifiedGallery } from 'justified-gallery';
import 'justified-gallery/style.css';

defineProps<{ images: { src: string; thumb: string; alt: string }[] }>();

const container = ref<HTMLDivElement>();
let gallery: JustifiedGallery | undefined;

onMounted(() => {
  gallery = new JustifiedGallery(container.value!, { rowHeight: 160 });
  gallery.init();
});

onBeforeUnmount(() => gallery?.destroy());
</script>

<template>
  <div ref="container" class="justified-gallery">
    <a v-for="image in images" :key="image.src" :href="image.src">
      <img :src="image.thumb" :alt="image.alt" />
    </a>
  </div>
</template>
```

More in the [Vue guide](/Justified-Gallery/vue/).

  </TabItem>
</Tabs>

Note the `justified-gallery` class already on the container: the stylesheet uses it to hide the gallery until it's laid out, avoiding a flash of unstyled images.

Continue with the [Getting Started guide](/Justified-Gallery/getting-started/), or jump straight to the [React](/Justified-Gallery/react/) or [Vue](/Justified-Gallery/vue/) guide.
