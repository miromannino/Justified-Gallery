File Gallery

E2E playright test cases showcase. Open each page and check that the described behavior.

Basic behavior

  • basic_gallery.html

    A gallery of mixed-aspect-ratio images should lay out into justified rows that fill the full container width, with no gaps or overlaps between images.

  • figures_gallery.html

    Same as basic_gallery, but each entry is a <figure> instead of an <a>. Layout should look identical to a normal gallery.

  • callbacks.html

    Open the devtools console: rowflush, resize, and complete events should be logged as the gallery builds and as the window is resized.

  • captions_and_destroy.html

    Images with a title should show a caption on top of them. After destroy() runs, only the originally hand-authored caption (on the first image) should remain; all JG-created captions and styling should be gone.

  • small_thumbnails.html

    Images should start as low-res thumbnails and be swapped for a higher-res version once laid out, without a visible blank flash or broken-image icon during the swap.

  • image_errors.html

    Some images intentionally fail to load. They should be silently skipped (no broken-image icons, no gaps in the grid) while the remaining images still fill the row and the gallery still finishes loading.

Layout options

  • margins.html

    Seven galleries with different margins/border combinations (0/1/10/20px margins, 0/5/20px borders). The visible gap between images and the gap around the gallery edge should visibly grow from top to bottom, matching each label.

  • max_row_height.html

    Each gallery has just two portrait images, which naturally form a very tall row when justified. In the first ("capped") gallery the row should be capped at a modest height; in the second ("uncapped") gallery the row should be allowed to grow very tall.

  • last_row.html

    Six galleries, same images, one per lastRow mode. The last (partially filled) row should: stretch to fill the row (justify), stay left-aligned at natural size (nojustify/left), be centered (center), be flush right (right), or not be shown at all (hide).

  • max_rows_count.html

    Only the first 2 rows of images should be visible; the rest of the images should not be rendered at all.

  • vertical_images.html

    A gallery of tall portrait images. Several images should fit side by side per row, each remaining tall/narrow (not cropped or distorted into a wide shape).

  • square_images.html

    A gallery of square images. Every image should stay visually square after layout, never stretched into a rectangle.

  • same_size_images.html

    A gallery where every image is identical. The result should look like a perfectly even grid, all tiles the same size.

Content edge cases

  • text_entries.html

    The gallery mixes photos with plain text entries and an image-less link with text inside it. The text entries should sit in the grid alongside the photos at a reasonable size, without breaking the row layout, and should not show a caption.

  • link_around_img.html

    Each entry is a <div> wrapping a <a><img></a> instead of a plain <a><img></a>. The gallery should still lay out normally, with a visible 15px gap between images.

  • thumbnail_path.html

    A custom thumbnailPath function always resolves to the largest thumbnail variant. Every image should end up showing its largest/highest-quality version, regardless of its on-screen size.

Ordering

  • randomize.html

    The images should appear in a different order than they're listed in the page source. Reload the page a few times: the order should change each time.
